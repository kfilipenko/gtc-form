## Изменения

- Главная, /mira/ и защищённый voice-pilot используют один контроллер. Нет обязательной галочки перед первым сообщением; сервер не требует guest_consent и не приписывает его посетителю.
- Внутренняя гостевая карточка остаётся технической связью истории и приглашения с сессией. Новые карточки имеют consent_personal_data=false, consent_communication=false, marker mira-guest-notice-v2. Имя/email/телефон не запрашиваются для начала разговора. Cookie и история до 30 дней сохранены; уведомление и страница конфиденциальности описывают это. Исторические согласия не изменены.
- Начало нового ответа становится видимым в контейнере и на странице телефона. Пользовательская прокрутка во время ожидания отменяет автоматическое перемещение. Загрузка истории не прокручивает страницу по каждой реплике. Озвучивание и появление текста остаются синхронными.
- Короткие уточнения в контексте поездки учитываются для передачи в приложение после четырёх законченных обменов. Прямые вопросы о проекте/входе/кодах остаются в поддержке.
- «Да», «Давайте», «Можно», «Покажи» после предложения гостевого доступа разрешаются в явный запрос приглашения; отказ, отсутствие предложения и ошибка выдачи не запускают автоматическую выдачу.
- Прямой запрос посмотреть приложение распознаётся сразу. Код выдаёт только прежний серверный ledger после проверки источника; модель его не сочиняет. Ошибки empty/unavailable/expired/disabled имеют отдельные ответы без повторного опроса о поездке.
- Контекст модели запрещает повторно спрашивать известные параметры и обещать поиск отелей без инструмента. Повтор уже заданного вопроса удаляется из ответа.
- 👍/👎 и комментарии, контроль происхождения запросов, права доступа, ограничения частоты и прежний лимит гостевой сессии сохранены.

## Проверки

TypeScript build; полный набор серверных тестов; 24 браузерные проверки (390×844 и 1440×844, главная и /mira/), длинный ответ, видимость начала, отсутствие горизонтального переполнения, отсутствие фиктивного consent, наличие thumbs.
Браузер: запустить `python3 -m http.server 4197 --bind 127.0.0.1 --directory projects/travelgtc/public`, затем `NODE_PATH=/var/www/gtc-form/node_modules node projects/travelgtc/operations/chat-followup/browser-check.cjs`.
Реальная PostgreSQL: создание гостевой сессии и оба consent=false проверены внутри отменённой транзакции; тестовых записей не сохранено.
Один синтетический запрос к Azure: Мальдивы/даты/бунгало/двое → «Покажи варианты отелей». Мира предложила гостевое знакомство вместо повторного опроса. Фактическая стоимость этого запроса не измерена. Реальные коды для тестирования не выделялись.
Браузерный тест использует mock API: это не утверждение о полной проверке микрофона физического телефона. Голосовой тракт не изменялся.
