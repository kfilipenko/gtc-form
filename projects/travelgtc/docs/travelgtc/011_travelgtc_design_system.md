# TravelGTC — описание дизайна сайта

## 1. Общая концепция

TravelGTC — это современный travel-клуб и платформа вовлечения людей в сообщество путешественников, организаторов маршрутов и партнёров.

Дизайн должен передавать три смысла:

**Путешествия** — свобода, впечатления, красивые места, новые маршруты.
**Сообщество** — люди, доверие, встречи, события, клубная атмосфера.
**Бизнес-возможность** — партнёрская сеть, развитие, системность, участие в современном проекте.

Сайт не должен выглядеть как обычная MLM-страница или агрессивная бизнес-презентация. Он должен восприниматься как **премиальный travel-клуб с понятной воронкой участия**.

Главная эмоция сайта:
**Хочу быть частью этого круга людей, путешествовать, создавать маршруты и развивать возможности вокруг себя.**

# 2. Визуальный стиль

## Характер дизайна

Стиль:
**premium travel club + digital network + lifestyle community**

Визуальное направление:

* крупные атмосферные travel-фотографии;
* тёмный глубокий фон;
* бирюзовые и лаймовые акценты;
* карточная структура;
* компактные блоки;
* минимальное пустое пространство;
* чёткая иерархия;
* современная инфографика;
* ощущение международности и доверия.

Сайт должен быть плотным, собранным и энергичным. Не допускать чрезмерных вертикальных отступов, больших пустых зон и рыхлой композиции.

# 4. Типографика

## Основной шрифт

Использовать один современный sans-serif:

**Inter** или **Manrope**

Рекомендуемый вариант: **Manrope** для всего сайта.

## Размеры

### Hero H1

Desktop: `56–68px`
Line-height: `1.05–1.12`
Weight: `800`

Mobile: `36–42px`
Line-height: `1.1`

### Заголовок секции H2

Desktop: `34–42px`
Line-height: `1.15`
Weight: `700–800`

### Подзаголовок / lead text

Desktop: `18–22px`
Line-height: `1.45`

### Основной текст

Desktop: `16px`
Line-height: `1.45–1.6`

### Текст карточек

Title: `18–22px`, weight `700`
Body: `14–16px`, line-height `1.45`

## Важное правило

Не делать большие межстрочные интервалы. Тексты должны быть компактными и читабельными.

Неправильно:

```css
line-height: 2;
margin-bottom: 48px;
```

Правильно:

```css
line-height: 1.45;
margin-bottom: 16px;
```

# 5. Компоновка и сетка

## Контейнер

Максимальная ширина контента:

```css
max-width: 1280px;
margin: 0 auto;
padding: 0 24px;
```

Для широких экранов можно использовать `max-width: 1360px`, но не растягивать текстовые блоки на всю ширину.

## Вертикальные отступы

Секции:

```css
padding: 56px 0;
```

Hero:

```css
padding: 88px 0 64px;
```

Мобильная версия:

```css
padding: 40px 0;
```

## Между блоками внутри секции

```css
gap: 24px;
```

Для карточек:

```css
gap: 16px или 20px;
```

## Карточки

Радиус:

```css
border-radius: 18px;
```

Тень:

```css
box-shadow: 0 16px 40px rgba(6, 26, 40, 0.12);
```

Граница:

```css
border: 1px solid rgba(0, 199, 217, 0.16);
```

# 6. Шапка сайта

## Стиль

Шапка должна быть тёмной, фиксированной или sticky, компактной.

Фон:

```css
background: rgba(6, 26, 40, 0.96);
backdrop-filter: blur(12px);
```

Высота:

```css
72–84px
```

Не делать слишком высокую шапку. В текущем варианте меню занимает много места. Нужно сделать компактнее.

## Логотип

Левая часть:

**TravelGTC**
Подпись: **Travel Network Lab**

Логотип должен быть читаемым, без мелкого перегруза.

## Меню

Пункты:

* Главная
* Путешествия
* Клуб
* Создать маршрут
* Бизнес-модель
* События
* О проекте
* Контакты

Активный пункт — тонкая бирюзовая линия снизу или мягкая capsule-подложка.

## Кнопки справа

Главная кнопка:

**Связаться со мной** — lime background.

Вторичные:

**Войти** — тёмная кнопка с border.
**Регистрация** — lime background.

Не делать кнопки слишком большими. Высота `42–46px`.

# 7. Hero-блок

## Назначение

Hero должен сразу объяснять идею сайта и вести к действию.

## Компоновка

Левая часть: текст и CTA.
Правая / фон: большая travel-фотография.

Лучший вариант: полноэкранный hero с фотографией на весь фон и тёмным градиентом слева.

## Фон hero

Использовать изображения:

* группа людей на закате у моря;
* Dubai rooftop / skyline;
* терраса отеля;
* путешественники, которые обсуждают маршрут;
* сообщество на вечернем мероприятии.

На изображении обязательно должен быть тёмный градиент слева:

Выделения:

# 9. Единая форма лида

## Где использовать

Форма должна быть на:

* главной;
* странице «Создать маршрут»;
* странице «Клуб»;
* странице «Бизнес-модель»;
* странице «Контакты».

Форма одна, но значение поля `interest_type` может автоматически подставляться в зависимости от кнопки или страницы.

## Текст формы

Заголовок:

**Выберите, как вам интересно участвовать в TravelGTC**

Подзаголовок:

**Это не регистрация и не обязательство. Это первый шаг, чтобы мы поняли ваш интерес и предложили подходящий формат участия.**

Поля:

* Имя
* Контакт
* Предпочитаемый канал связи
* Страна / город
* Что вам интересно?
* Есть ли у вас своя аудитория или группа?
* Комментарий
* Согласие на обработку данных

Кнопка:

**Отправить заявку**

После отправки:

**Спасибо. Заявка получена. Мы свяжемся с вами и предложим следующий шаг: консультацию, презентацию, участие в клубе или обсуждение вашей travel-идеи.**

# 12. Что нужно исправить в текущем дизайне

## Проблема 1. Слишком большие отступы

Уменьшить vertical spacing примерно на 30–40%.

Правило:

```css
section {
  padding: 56px 0;
}
```

Не использовать `padding: 100px 0`, кроме крупных landing-hero.

---

## Проблема 2. Слишком крупные интервалы между строками

Для заголовков:

```css
line-height: 1.08;
```

Для текста:

```css
line-height: 1.45;
```

---

## Проблема 3. Меню занимает много высоты

Сделать header компактнее:

```css
height: 76px;
```

Логотип и подпись — в одну компактную группу.

---

## Проблема 4. Слишком много пустых зон на светлом фоне

Добавить плотные карточки, сетки 3–4 колонки, CTA-плашки, горизонтальные схемы.

---

## Проблема 5. Не хватает бизнес-процесса

На главной обязательно добавить блок:

**Как вы становитесь частью сообщества**

И форму:

**Выберите мой формат участия**

# 14. Финальная формула дизайна

TravelGTC должен выглядеть как:

**Премиальный travel-клуб с современной цифровой воронкой участия.**

Не как:

* туристический блог;
* каталог туров;
* сетевой бизнес из 2000-х;
* лендинг с обещанием дохода;
* пустая красивая презентация.

Дизайн должен вести пользователя по маршруту:

**Мечта → Сообщество → Роль → Заявка → Консультация → Участие.**
