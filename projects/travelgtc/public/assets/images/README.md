# TravelGTC Images

Use this section for TravelGTC website image materials.

## Folders

```text
inbox/
processed/
```

## Rules

1. `inbox/` is for raw materials from the Project Owner.
2. `processed/` is for optimized images approved for website use.
3. Public pages should use files from `processed/`.
4. Do not delete originals from `inbox/` unless the Project Owner asks for cleanup.
