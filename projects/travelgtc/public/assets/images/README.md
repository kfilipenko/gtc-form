# TravelGTC Images

Use this section for TravelGTC website image materials.

## Folders

```text
inbox/
inbox/foto/
processed/
```

## Rules

1. `inbox/` is for raw materials from the Project Owner.
2. `inbox/foto/` currently stores the first visual mockups and design references.
3. `processed/` is for optimized images approved for website use.
4. Public pages should use files from `processed/`.
5. Do not delete originals from `inbox/` unless the Project Owner asks for cleanup.
