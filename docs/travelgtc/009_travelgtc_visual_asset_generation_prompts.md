# TravelGTC - Visual Asset Generation Prompts

- Project: TravelGTC
- Concept: Travel Network Lab
- Document type: Production image prompts
- Version: 0.1
- Date: 2026-07-08
- Status: Ready for Project Owner image generation

## 1. Purpose

Use these prompts to generate production images for the Travel Network Lab website.

The uploaded mockups in `projects/travelgtc/public/assets/images/inbox/foto/` are design references only. They should guide mood, proportions and visual style, but they must not be used as real public page content.

## 2. Global Style Rules

Apply these rules to every prompt:

```text
Photorealistic modern travel-club editorial image, clean premium website style, international scale, natural light, realistic people, authentic travel emotions, deep navy and ocean blue mood with subtle turquoise and lime accents, high-end but not luxury-snobbish, calm optimistic atmosphere, no text, no logo, no watermark, no UI mockup, no poster typography, no distorted hands or faces.
```

Recommended formats:

1. hero and wide blocks: `16:9`, at least `2400x1350`;
2. vertical/card images: `4:5`, at least `1600x2000`;
3. square thumbnails: `1:1`, at least `1600x1600`.

## 10. Negative Prompt

Use this negative prompt when the image generator supports it:

```text
text, letters, words, logo, watermark, poster, banner, UI screen, readable phone screen, fake app interface, deformed hands, extra fingers, distorted faces, over-smiling stock photo, luxury yacht stereotype, aggressive business seminar, MLM presentation, money, cash, charts, neon nightclub, dark underexposed photo, low-resolution, cartoon, illustration, 3D render.
```
