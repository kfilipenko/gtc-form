## 1. Purpose

This document is the working copy draft for the `Возможности` page before implementation.

The page must stop looking like a neutral classification page. It should become a motivational sales page where each scenario speaks to a clear audience, exposes a recognizable need and invites the user to continue the conversation with Mira.

Working rule for future TravelGTC page copy:

```text
First agree the selling text in a Markdown document, then implement the approved version in HTML/CSS.
```

## 2. Page Role In The Funnel

The `Возможности` page sits between first interest and Mira conversation.

It should help the visitor answer:

1. why Travel Advantage may be useful personally;
2. which life or business need is closest;
3. whether the next step is Free Guest Pass, Membership comparison, Ambassador discussion or Mira consultation.

The page should not disclose internal Mira dialogue scripts. Mira receives those rules through AI instructions and knowledge files.
