# Границы исследования курса

В этой сессии ранее прочитаны1548 доступных строк русских субтитров16 уроков Getting Started RU в профиле Owner. Это не полный просмотр аудио/видео. Состав, числа строк, время наблюдения и контрольные суммы сохранены в source-evidence-v4.json; исходный текст не передаётся.

Урок08 Online Presentation: строки1–39, связан с K034. Урок10 Objections:1–155, связан с K013/K029/K030. Урок11 First48h:1–66, связан с K032. K020/K022 содержат агрегированную метаинформацию. Точные короткие границы находятся в subtitle-boundaries.json. Таймкоды концов текста неизвестны; длительности видео не заменяют их. Пропуски не восстановлены.

Историческая связь с уроками сохранена в historical_source_ids и historical_source_row_ranges. Пересмотр13 редакционных рекомендаций удалил необходимость закрытого урока как доказательства. K020/K022/K023 описывают исследование и UI, остаются внутренними. Неизвестность условий загрузки полных закрытых курсов во внешний AI локализована в restrictions-and-uncertainties.json.
