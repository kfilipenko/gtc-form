# Definition Of Done Checklist

- Project: <PROJECT_NAME>
- Task: <TASK_CODE>
- Date: <DATE>

## Required For Every Completed Task

1. Task or decision is recorded.
2. Relevant source files are changed.
3. Documentation/registers are updated where relevant.
4. Verification is run.
5. Generated artifacts are cleaned/restored.
6. `git diff --check` passes.
7. Worktree is reviewed before commit.
8. Commit is created.
9. Final response includes result, links, tests and commit hash.

## Public Page / Publication Additions

1. Public URL returns expected status.
2. Expected live text marker is present.
3. Navigation or hub link is present.
4. No duplicate canonical public document was created.
5. Desktop/mobile visual check completed when user-facing.

## Backend/API Additions

1. Syntax check passed.
2. Focused tests passed.
3. Guard/permission failure path tested.
4. Audit/evidence behavior documented where relevant.

## Deploy Additions

1. Deploy command ran or publication was otherwise verified.
2. Live smoke checks passed.
3. Rollback/backup note exists for risky releases.
